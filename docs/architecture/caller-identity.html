Caller Identity

Every adapter stamps one authenticated caller shape into context. Services consume that shared caller through a small resolver interface and enforce their own authorization rules.

1. Shared contract

internal/caller is the one process-local caller identity package. It is not an auth service and it is not a permission engine. It is the typed context contract shared by protocol adapters and service application layers.

package caller

type Caller struct {
    UserID   string
    MemberID types.MemberID
    ProjectID  types.ProjectID
    Role     string
}

type Resolver interface {
    ResolveCaller(ctx context.Context) (Caller, error)
}

func ContextWithCaller(ctx context.Context, caller Caller) context.Context

type ContextResolver struct{}

The resolver trims fields and fails when both UserID and MemberID are empty. A user-only caller is valid for user-owned RPC flows. A member caller is valid for agent/member flows. A caller may carry both when an adapter can authenticate the user and resolve the acting member.

3. Service boundaries

Services depend on caller.Resolver, not on protocol packages. This lets the same service run behind JSON-RPC, MCP, HTTP, tests, and future daemon strategies without changing the service constructor.

LayerResponsibility
Daemon / RPC / MCPAuthenticate the request, resolve any actor member when the protocol has one, and stamp caller.Caller.
Service app layerResolve the shared caller and enforce service-specific authorization before state changes.
Domain layerValidate state transitions and inputs. It does not read context and does not know users or transport.
Repository layerPersist and load records. It does not authorize callers.

4. Member storage

The canonical durable member table is members. A member belongs to a project, but the table name reflects the domain record, not one relationship. This is a hard-cutover schema: new local databases create members; old project_members databases are not kept alive through compatibility views or fallback reads.

CREATE TABLE members (
    member_id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL DEFAULT 'local',
    project_id TEXT DEFAULT '',
    project_id TEXT NOT NULL,
    member_type TEXT NOT NULL,
    lifecycle_state TEXT NOT NULL,
    harness_kind TEXT DEFAULT '',
    member_json TEXT NOT NULL,
    registered_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    last_seen_at TEXT DEFAULT ''
);
