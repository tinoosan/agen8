# Shared work graph UI verification

This branch integrates the selected staging UI source recovered read-only from the user's canonical nested staging checkout. It preserves Agen8 branding, palette and the force layout. Work-state shelves sit beside the graph; the inspector explains the selected record, blockers/results, connections and history. The browser remains read-only, with no registration, claims, creation/edit forms or review gate.

Shelves group blocked, working, planned and finished work, paginate at 25 rows, and reveal selections/search matches. Manual folds and graph positions survive refresh. Selecting a shelf item or connection clears filters that could hide it. Closing details returns keyboard focus. Project loading and unavailable deep links have explicit states. Desktop selection waits for graph measurement and recenters after inspector resize or search remount. Competing automatic fit behavior was removed. Obsolete mobile CSS that hid work text was removed.

Local browser evidence uses the actual native Sites preview and real local D1 with a labelled synthetic project; local preview sign-in is not real hosted Sites authentication. Checks cover readable centered selection, filter clearing, connection navigation, lazy history, manual-fold/layout retention, search empty states, visible mobile titles/blockers, viewport bounds at 1440/768/390 and absence of browser page errors. Screenshots are in ignored `output/playwright/desktop.png`, `mobile.png`, `details-768.png` and `details-390.png`; assertions are recorded in `checks.json`. They have not been published or sent to external callbacks.

`npm run test:e2e` is prepared for the actual owner-private dev Site and deployed D1. Its preflight requires the exact HTTPS dev origin, two saved genuine dedicated account sessions and explicit `AGEN8_E2E_ALLOW_WRITES=yes`. The owner's session writes and archives a synthetic project; the outside-audience and signed-out sessions must be denied, including spoofed identity headers. It uses no request interception or platform API substitute. Missing sessions fail clearly. This live suite has not run and requires approval for sessions and staging writes; do not widen the private audience to satisfy a test.
